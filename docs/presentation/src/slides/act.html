ACT stands for Action Chunking with Transformers, from Stanford's ALOHA project (2023). The ResNet turns the image into a 15 by 20 grid of feature vectors; each cell becomes a token. LeRobot uses 1 decoder layer because the original code effectively only used the first of its 7. Parameter counts are read from the trained weights file.
