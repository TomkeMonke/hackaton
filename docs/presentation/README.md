# Prezentacja: Pinecone Robot - How It Works

12 slajdow po angielsku: detekcja szyszek (HSV), odleglosc z glebi, jazda po obrazie,
chwyt polityka ACT (dane, model, trening), pelny cykl i stan projektu (wg `docs/STATUS.md` z 2026-09-27).

- `index.html` - gotowa prezentacja, jeden plik. Otworz w przegladarce: strzalki / spacja / klik = nastepny slajd.
- `src/deck.json` + `src/slides/*.html` - zrodlo (jeden slajd = jeden plik, notatki prelegenta w `<aside>`).
- `build.py` - sklada `src/` w `index.html`: `python docs/presentation/build.py`.
